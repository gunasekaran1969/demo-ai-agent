# Demo AI Agent

A no-API-key demo AI agent built with Next.js and Vercel-ready UI.

## Features
- Chat-style interface
- No API key required
- Answers general questions using built-in demo logic
- Works locally and on Vercel

## Run locally

```bash
npm install
npm run dev
```

Then open: http://localhost:3000

## Deploy to Vercel

1. Push this repo to GitHub.
2. Import it into Vercel.
3. Deploy without any environment variables.

Your app will usually be available at:

https://demo-ai-agent.vercel.app

Note: this is a demo AI agent without external model access, so it responds using built-in logic rather than a hosted LLM.
